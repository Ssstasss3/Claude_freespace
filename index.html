Vanilla JS Excel - Help

Keyboard Shortcuts

  • Arrow Keys - Navigate cells
  • Tab - Move right
  • Shift+Tab - Move left
  • Enter - Move down / Confirm edit
  • F2 - Edit cell
  • Escape - Cancel edit
  • Delete - Clear cell content
  • Ctrl+C/X/V - Copy/Cut/Paste
  • Ctrl+Z/Y - Undo/Redo
  • Ctrl+B/I/U - Bold/Italic/Underline
  • Ctrl+S - Save file
  • Shift+Click - Range selection
  • Ctrl+Click - Multi-selection

Formulas

  • =SUM(A1:A10) - Sum of range
  • =AVERAGE(A1:A10) - Average of range
  • =MIN(A1:A10) - Minimum value
  • =MAX(A1:A10) - Maximum value
  • =COUNT(A1:A10) - Count numbers
  • =COUNTA(A1:A10) - Count non-empty
  • =IF(A1>10,"Yes","No") - Conditional
  • =A1+B1*2 - Math expressions
  • =CONCAT(A1,B1) - Join text
  • =ROUND(A1,2) - Round number
  • =ABS(A1) - Absolute value
